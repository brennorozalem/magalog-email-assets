# Magalog Email & Card Assets

Static visual assets (animated GIF and web embed) for HTML email headers and web cards.

- `rainbow-bar-card.gif` — 600x5px 32-frame animated rainbow accent bar for HTML emails (Gmail, Outlook Web/New Outlook, Apple Mail)
- `rainbow-bar-card.html` — CSS-animated rainbow bar for web cards/iframes (`?h=5&r=12&bg=0058cc&speed=4.5&mode=flow|wave|static`)
